 🚲 AdventureWorks Sales Analysis - Power BI Dashboard

  📌 Project Overview
This project involves an end-to-end data analysis of the renowned **AdventureWorks** dataset. The interactive Power BI dashboard provides a comprehensive view of sales performance during the February - March period, focusing on order statuses, regional revenue contributions, and customer payment preferences.

   🛠️ Tools & Technologies Used
- Business Intelligence Tool: Power BI Desktop
- Data Source: AdventureWorks Database
- Skills Applied: Data Modeling, DAX (Data Analysis Expressions), Time-Intelligence calculations, and Advanced Data Visualization (Waterfall charts, Gauges, etc.)

   🔍 Key Insights & Findings
1. Goal Tracking: The dashboard tracks the overall order total against a set target of 20M, showing current progress at 10M for the selected period.
2. Order Status Breakdown: A significant portion of orders are successfully 'Shipped' (approx. 4M), but tracking 'Canceled' (2.1M) and 'Processing' orders highlights areas for operational improvement.
3. Regional Performance (Waterfall Analysis): The Waterfall chart reveals that North America is the primary driver of revenue growth, offsetting negative trends in Europe and Asia during this period.
4. Payment Preferences: Customers show a strong preference for **Credit Cards** (approx. 68.5%) over **PayPal** (approx. 31.5%) for order transactions.
5. Trend Analysis: The time-series line chart provides granular visibility into daily and weekly order total fluctuations, enabling better forecasting.

   🚀 How to Open the Project
1. Download and install [Power BI Desktop](https://powerbi.microsoft.com/desktop/).
2. Clone this repository or download the ZIP file.
3. Open the `.pbix` file using Power BI Desktop.
4. Use the built-in slicers (Product Category, Region, Shipping Method) to interact with the data dynamically!
