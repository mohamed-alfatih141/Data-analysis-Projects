
# 📊 Amazon Sales Analysis Dashboard

An interactive **Amazon Sales Analysis** project built with Microsoft Excel to analyze sales performance, identify top-performing products and categories, understand customer behavior, and compare sales across different countries and time periods.

The project transforms raw sales data into meaningful insights using **Pivot Tables, data analysis, and an interactive dashboard**.

---

## 📌 Project Overview

This project analyzes Amazon-style e-commerce sales data to answer important business questions such as:

- 💰 What are the total sales?
- 📦 How many orders were placed?
- 👥 How many customers are represented?
- 🏆 Which products generate the highest sales?
- 🗂️ Which product categories perform best?
- 🌍 Which countries generate the most revenue?
- 📈 How do sales change over time?
- 👤 Which customers contribute the most to revenue?
- 🇦🇺 Which market requires the most attention?

The analysis is presented through an Excel dashboard designed to provide a quick overview of sales performance and support data-driven decision making.
