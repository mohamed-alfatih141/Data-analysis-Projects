# 🚗 Tesla Sales Dashboard | Power BI

## 📊 Project Overview

This project presents an interactive **Tesla Sales Dashboard** built using **Microsoft Power BI**.

The dashboard analyzes Tesla sales data from **2023–2024** and provides insights into sales performance across different car models, countries, colors, and battery types.

The goal of this project is to transform raw sales data into an interactive and easy-to-understand dashboard that supports data analysis and business insights.

---

## 🎯 Objectives

- Analyze Tesla sales performance.
- Compare sales across different car models.
- Analyze sales distribution by country.
- Explore sales by vehicle color.
- Compare different battery types.
- Track sales trends over time.
- Create an interactive dashboard using Power BI.

---

## 📈 Dashboard Features

The dashboard includes:

- 💰 **Average Sale Amount**
- 🚗 **Units Sold**
- 🚘 **Sales by Car Model**
- 🌍 **Sales by Country**
- 🎨 **Sales by Color**
- 📅 **Sales Over Time**
- 🔋 **Battery Type Filter**
- 🚘 **Car Model Filter**

Interactive slicers allow users to filter the dashboard and explore the data dynamically.
