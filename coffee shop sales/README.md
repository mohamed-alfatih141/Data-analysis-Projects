 ☕ Coffee Sales & Loyalty Program Analysis - Power BI Dashboard

  📌 Project Overview
This project features an interactive Power BI dashboard designed to analyze the sales performance of various coffee types and evaluate the business impact of a customer loyalty program. The analysis aims to provide actionable insights into product profitability and customer purchasing behavior.

   🛠️ Tools & Technologies Used
- Business Intelligence Tool: Power BI Desktop
- Data Transformation: Power Query
- Calculations & Measures: DAX (Data Analysis Expressions)
- Data Visualization: Interactive charts, KPIs, and UI Design

   🔍 Key Insights & Findings
1. Loyalty Program Success: Revenue is split exactly 50/50 between loyalty card members and non-members, demonstrating high adoption and effectiveness of the loyalty program.
2. Top Performing Products: The Excelsa and Liberica coffee varieties lead the market in both total sales volume and overall profitability.
3. Profit Margins:** Analyzed the relationship between unit price, total size sold, and profit to highlight areas for potential pricing optimization.

   📂 Repository Contents
- Coffee_Sales_Dashboard.pbix: The complete Power BI project file containing the data model, DAX measures, and visuals.
- Dashboard_Screenshot.png: A high-resolution image of the final dashboard.

   🚀 How to Open the Project
1. Download and install [Power BI Desktop]
2. Clone this repository or download the files as a ZIP.
3. Open the `Coffee_Sales_Dashboard.pbix` file using Power BI Desktop.
4. Interact with the visuals, apply filters, and explore the insights!
